Модель

Модели читаются из внутренней папки приложения (быстрый mmap). Кнопка «Импорт» копирует .gguf из любого места — Проводник, Загрузки, облако. Проектор mmproj-*.gguf подхватывается автоматически для VL-моделей.

Запуск движка

Контекстсколько текста держит в памяти
Потоки CPUбольше — быстрее и горячее
Тип KV-кэшаq8_0 — вдвое меньше памяти
Flash Attentionэкономит память на длинном контексте
Слотов запросовпараллельные диалоги
mmap моделивыкл = загрузить в RAM целиком
Температура сэмплинга0.3 точно, 1.0 креативно

Рассуждения

Думать перед ответомLFM3 умеет reasoning; выкл = быстрее и короче
Сохранять рассуждения в контекстевыкл = прошлые «мысли» вырезаются, экономит окно
Показывать блок рассужденийтолько отображение, на скорость не влияет
Лимит размышлений0 = без лимита; обрезает «мысли» по токенам
Лимит ответавключая рассуждения
Параметры уходят в сервер как chat_template_kwargs — применяются сразу, перезапуск движка не нужен. Модели без поддержки рассуждений эти поля просто игнорируют.
